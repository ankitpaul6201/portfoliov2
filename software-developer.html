What is CP-Vault and how did Ankit build it?

CP-Vault is a Manifest V3 Chrome Extension engineered by Ankit Paul that automatically archives accepted solutions from competitive programming platforms (LeetCode, Codeforces, CodeChef, HackerRank) directly to GitHub. It uses SHA-256 code hashing to eliminate duplicate commits, formats READMEs with complexity tags, and maintains an offline retry queue for resilient background sync.

What is Campus Buddy and its architecture?

Campus Buddy is a mobile-first peer-to-peer student marketplace built by Ankit using React, Capacitor, Tailwind CSS, Node.js, Express, and MongoDB. It features verified university email authentication, real-time buyer-seller messaging, and sub-50ms database query latency under tested workloads.

What databases and backend architectures does Ankit Paul utilize?

Ankit designs relational architectures with PostgreSQL (Prisma, raw SQL) for structured transactional data, and document architectures with MongoDB for dynamic schemas. He builds backends using Node.js, Express, FastAPI, and Next.js Route Handlers with JWT authentication and strict input validation via Zod.
