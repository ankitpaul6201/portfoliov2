1. Centralized Choke-Point LLM Gateway Architecture

In modern production systems, uncontrolled client calls to commercial LLM providers (OpenAI, Anthropic, Google Gemini) fail catastrophically under traffic surges due to strict RPM (Requests Per Minute), TPM (Tokens Per Minute), and TPD (Tokens Per Day) thresholds. To solve this, Ankit engineered an industrial Centralized Choke-Point LLM Gateway (The Relay) that acts as an autonomous scheduler between multi-tenant clients and upstream foundation models.

  • Dual Leaky Token Buckets: Enforces sub-millisecond quota refill rates across RPM and TPM while maintaining rolling 24-hour persistent TPD ledgers.
  • Earliest Deadline First (EDF) Scheduling: Dynamically prioritizes interactive latency-sensitive user prompts over asynchronous background summarization jobs.
  • Adaptive L0–L4 Degradation Ladder: When upstream APIs enter saturation or unviable latency states, the gateway drops through an adaptive degradation ladder in <1ms, shedding dead queries and falling back smoothly to local zero-token TF-IDF/BM25 extractive search.

2. Zero-Hallucination Grounded RAG Pipeline

Traditional naive RAG architectures suffer from semantic context contamination, prompt injection vulnerabilities, and subtle factual hallucinations. Ankit designed a research-grade grounded RAG pipeline indexing dense academic papers (including Attention Is All You Need, Moshi, and Dynamic Chunking) that mathematically verifies citation entailment.
